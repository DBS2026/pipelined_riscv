Every value on this page was recorded from a simulation of your Verilog (riscv_top.v, sampled once per clock). The program runs one of each instruction type. Click any row to see what every block in each stage did with the real numbers.

IFIDEXMEMWB stall (held in stage)✕ flushed

Values are signed decimal unless shown in hex. Each stage card shows the cycle in which the instruction was in that stage; open "All signals" for the raw values of every wire at that moment. Registers read in ID can be stale: when the EX card shows a forwarded operand, that forwarded value is the one actually used.
